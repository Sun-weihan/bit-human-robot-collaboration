### ★★★ 第一优先：AtsushiSakai/PythonRobotics

| 项 | 值 |
|---|---|
| 地址 | https://github.com/AtsushiSakai/PythonRobotics |
| 星标 | **30,681** |
| 语言 | Python |
| 最近更新 | 2026-10-06（**活跃**） |
| 许可 | MIT |
| 依赖 | numpy、scipy、matplotlib（**无重型依赖**） |

**为什么推荐**：仓库内有专门的 `InvertedPendulum/` 目录，包含两个文件：

| 文件 | 行数 | 对应题号 |
|---|---|---|
| `inverted_pendulum_lqr_control.py` | 192 | **题 4.3** |
| `inverted_pendulum_mpc_control.py` | — | 题 8.3（第 8 周） |

LQR 示例的代码结构（已实测源码）：

```
1. 定义物理参数 l_bar, M, m, g
2. get_model_matrix()  -> 构造线性化 A、B，并按 delta_t 离散化
3. solve_DARE()        -> 迭代求解离散 Riccati 方程
4. dlqr()              -> 算增益 K，返回闭环特征值
5. simulation()        -> 单步更新 x = Ax + Bu
```

**用法建议**：**不要直接抄**。正确用法是——

1. 自己先推 A、B、写 LQR
2. 把自己的结果与它对照，特别是：
   - 它的 A、B 与你的是否一致（注意它的 `Q = diag([0, 1, 1, 0])` 把位置和速度的代价设为 0）
   - 它用 **DARE（离散）**，你用 **CARE（连续）**，两者在 `delta_t` 足够小时应趋同
3. 差异出现时，先怀疑自己——除非你能说清为什么它对

**风险提示**：该仓库的 LQR 示例用的是**简化点质量模型**，与你题面中带
$(I + m l^2)$ 的形式略有差别。别把两者的公式混用。

**为什么推荐**：这是你**第 5 周（卡尔曼滤波）**的必读资源，你的学习计划"资源清单"
里已经列了它。但**第 4 周就该开始翻**——因为：

- 它的核心方法论是 **"建立直觉，而非形式证明"**，正好补足你第 4 周大量推导后的直观理解

- **用法**：写自己的实现 → 与 filterpy 对比数值 → 吻合才有信心往下走

**风险提示**：更新止于 2024-08，部分 notebook 基于 Python 3.6 时代。在 Python 3.13
下运行可能遇到个别兼容问题（主要是旧的 matplotlib API）。**建议只读不跑**，
或单独建一个 Python 3.10 环境。

**为什么推荐**：控制系统分析的瑞士军刀。第 4 周要用的具体函数：

| 函数 | 用途 | 对应题号 |
|---|---|---|
| `control.ctrb(A, B)` | 直接算可控性矩阵 | **题 4.2** |
| `control.obsv(A, C)` | 可观性矩阵 | 题 4.2 |

**用法建议**：题 4.2 的 PBH 判据和题 4.4 的 Lyapunov 方程，用它做**交叉验证**——
你的手算结果和它算的对上，才算真的过了。注意：**它的 `lqr()` 也是调 ARE solver，
和 `scipy.linalg.solve_continuous_are` 本质相同**，不构成独立验证。
